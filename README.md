# OpenAI API Tester

This repo provides a simple Python CLI tool and a Postman collection to test your OpenAI GPT API key and monitor token usage and cost.

## 🧪 CLI Script

### `openai_key_tester.py`

Run with:

```bash
python openai_key_tester.py sk-your-openai-api-key
```

## 📫 Postman Collection

Import `postman/openai_chat.postman_collection.json` into Postman to test the chat API.
